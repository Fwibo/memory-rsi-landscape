# memory-RSI：记忆 × 递归自我改进文献调研

关于 LLM 智能体的**记忆系统**和**自我改进 / 递归自我改进（Recursive Self-Improvement, RSI）**之间关系的文献调研笔记，用于给一篇 memory-RSI 方向的论文做定位。资料截止 2026-10-28，文档为中文。

## 主要结论

1. **RSI 在 2026 年已经是一个独立方向。** ICLR 2026 办了 RSI 专题 workshop；2026 年 7–10 月至少出了 6 篇 RSI 专题综述。
2. **被改进的对象有 6 类**：权重、数据 / 课程 / 奖励、代码 / 脚手架 / harness、记忆 / 经验 / 技能、工具、研究流程。2026 年的重心在 harness 和记忆 / 技能：自进化编码智能体综述统计的 75 篇 2026 年方法里，69 篇改的是"资产"（记忆、技能、工具、上下文）或架构，只有 6 篇改权重。
3. **综述对 RSI 的定义在收紧**，要求"改进机制本身被改，并且这个改动影响下一次改进如何发生"。按这个标准，目前没有系统达到开放式 RSI：Liu 等分级的 187 个工作没有一个到 L5，AI4AI 审计的 35 个系统没有一个能自己设定目标或反馈。
4. **记忆在综述里只是被改进的对象。** 精读的 21 篇综述都把记忆当作 harness 的一个组件，没有一篇把它当作递归本身的载体。Wu 等给出了一个入口：如果一条记忆指导的是诊断或更新选择，它就属于改进者。
5. **记忆演化有风险证据**：反复整合后效用先升后降、错误经验被打出偏高分数（Echo Gap）、整合时丢失使用范围约束等。
6. **ICLR 2027 投稿**中，演化记忆架构的工作大多由固定的 meta-agent 驱动（A 类 14 篇）；改进者自身也在演化的工作只有 10 篇（B 类）。

## 方法与核验

- 两轮检索：arXiv API + WebSearch；第二轮精读了 21 篇综述，并和 Chen 等综述公开的 1,250 篇语料表、3 个 awesome-list 做了比对补漏。
- 269 篇论文全部通过 arXiv 层核验（`verify_papers.py`），并逐篇对照 arXiv 原标题检查 ID 是否对应。Preprints.org 上的 5 篇综述不在 arXiv，未经该脚本核验。
- 会议 / 期刊信息来自检索页面，没有逐一核对论文集，报告中用 `*` 标注。表中数字来自摘要或综述转述，正式引用前请核对原文。
- ICLR 2027 投稿均为匿名在审稿件，信息来自 OpenReview 上的公开摘要。
- 2026 年这个方向的论文量很大（每季度约 500 篇），本调研做不到穷尽。
